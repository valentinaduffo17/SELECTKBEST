Fundamentos Teóricos: SelectKBest & ANOVA F-value

Cómo la prueba estadística f_classif evalúa y descarta multicolinealidades y ruido.

calculate 1. Cálculo de Razón F

Se descompone la varianza entre grupos (clase y=yes vs y=no) dividida por la varianza dentro de los propios grupos. Un F mayor significa una dispersión inter-clase categóricamente diferenciable.

filter_alt 2. Selección Greedy K=3

El algoritmo ordena las variables de forma descendente según el score estadístico univariante y retiene exactamente las k superiores, eliminando dimensionalidad sin asumir distribuciones lineales complejas.

visibility 3. Conclusión Práctica

duration es el predictor más decisivo (duración de la conversación), seguido del entorno económico (nr.employed) y si el cliente ya había sido contactado previamente (pdays < 999).

select_kbest_reproducible.py
Python 3.10+ / scikit-learn 1.3+ 
import pandas as pd
from sklearn.feature_selection import SelectKBest, f_classif

# 1. Cargar el dataset de campañas bancarias
df = pd.read_csv("bank-additional.csv", sep=';')

# 2. Separar predictores numéricos y variable objetivo
numeric_features = df.select_dtypes(include=['int64', 'float64']).columns
X = df[numeric_features]
y = df['y'].apply(lambda val: 1 if val == 'yes' else 0)

# 3. Instanciar SelectKBest con prueba ANOVA F
selector = SelectKBest(score_func=f_classif, k=3)
X_reduced = selector.fit_transform(X, y)

# 4. Inspeccionar las variables elegidas ('duration', 'pdays', 'nr.employed')
selected_columns = X.columns[selector.get_support()]
print("Variables óptimas seleccionadas:", selected_columns.tolist())
# Output: ['duration', 'pdays', 'nr.employed']
